# Credit Delinquency Analysis

## Project Overview
This project explores customer credit and payment behavior to identify patterns associated with credit delinquency. The analysis focuses on understanding missed payments, credit utilization, and other customer attributes that may be associated with delinquency.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Data cleaning and exploratory data analysis

## Project Work
- Cleaned and prepared the dataset for analysis.
- Examined customer payment behavior and credit-related attributes.
- Created PivotTables and charts to summarize key patterns.
- Explored relationships between missed payments, credit utilization, and delinquency.
- Prepared reports summarizing findings and recommendations.

## Files Included
- Excel workbook containing the analysis and visualizations.
- PDF reports documenting the analysis and recommendations.

## Objective
To explore customer delinquency patterns and communicate findings that can support better credit-risk assessment.
